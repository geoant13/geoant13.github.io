# geoant13.github.io

Personal academic homepage of George Antoniou, served by GitHub Pages at
<https://geoant13.github.io/>.

It is a single static page with no build step:

- `index.html` holds all content and styles. Edit it directly; changes go live
  a minute or so after pushing to the default branch.
- `fonts/` holds self-hosted Commissioner and Literata (Latin and Greek subsets),
  both under the SIL Open Font License (licence texts included).
